## 网络设置：APN是灵魂

*   **MTN**: APN名称设为 `mtngh.com`（其余字段通常留空或默认即可）。
*   **Vodafone**: APN名称设为 `internet`（同样，其余字段默认）。

　　手动设置一下，重启手机，世界立刻就通畅了。这个小小的动作，能省去你80%的上网烦恼。
